### 🚀 Мои проекты

- **[Priority Flow](https://github.com/konozeka/priority_flow_bot)** — Полноценный Telegram-бот для управления задачами по матрице Эйзенхауэра. 
  *Реализовано:* асинхронная архитектура на `aiogram 3`, машина состояний (FSM) для диалогов, хранение данных в `SQLite`, inline-кнопки для управления статусами, модуль статистики и онбординг для новых пользователей.
  
- **[Toscrape Parser](https://github.com/konozeka/Toscrape-parser)** — Скрипт для веб-парсинга. Собирает структурированные данные (названия, цены, наличие) с веб-страниц и автоматически выгружает их в формат CSV для дальнейшего анализа.

- **[Python Practice](https://github.com/konozeka/python-practice)** — Набор утилит для автоматизации. Включает в себя скрипт для автоматической сортировки файлов по расширениям (с использованием `os` и `shutil`) и модуль визуализации данных на `matplotlib`.
